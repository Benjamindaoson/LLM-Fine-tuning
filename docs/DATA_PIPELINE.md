# 数据生产链路

```text
多源金融原文
  → 规范化 / 质量过滤 / SQLite 全局去重
  → source_id 稳定切分
  → 分层确定性抽样
  → 本地 Qwen3.8-27B 生成单轮与多轮样本
  → JSON 与对话结构校验
  → 内容去重 / 数据泄漏审计
  → Stage 1 / Stage 2 数据集
```

## 设计要点

- 支持 JSONL、JSON、CSV、Parquet 与目录递归读取。
- 百万级语料使用 SQLite 磁盘索引去重，不一次性加载进内存。
- 生成端使用有界异步队列、指数退避、错误日志与 source_id 断点恢复。
- 单轮样本扩大知识覆盖，多轮样本增强连续追问和上下文保持。
- Stage 2 聚焦数值推理与多轮分析，同时回放 20% 其他金融任务。
